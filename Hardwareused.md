## 🧰 Hardware Used

This project was built using low-cost embedded hardware designed for IoT prototyping and learning:

* ESP8266 NodeMCU V3 WiFi Development Board
* DHT11 Temperature & Humidity Sensor
* Solderless Breadboard (830-point)
* Jumper Wire Kit (Male-to-Male / Male-to-Female)
* Micro USB Cable (Data + Power)
