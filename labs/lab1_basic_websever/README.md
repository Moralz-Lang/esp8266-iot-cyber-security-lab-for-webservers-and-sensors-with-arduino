# 🧪 Lab 1 — ESP8266 Basic Web Server

## 🎯 Objective
Create a simple web server using ESP8266 that serves a basic HTML page.

---

## ⚙️ What This Lab Teaches
- ESP8266 WiFi connection
- Web server basics
- HTTP response handling

---

## 🔌 Hardware
- NodeMCU ESP8266

---

## 💻 How It Works
1. ESP connects to WiFi
2. Starts web server on port 80
3. Displays HTML page at IP address

---

## 🌐 Output
Open Serial Monitor → get IP → open in browser

Example:
http://192.168.x.x/

---

## 🧠 WHAT LAB 1 DEMONSTRATES

✔ First embedded web server
✔ WiFi connectivity
✔ HTTP response system
✔ Foundation for all IoT labs
