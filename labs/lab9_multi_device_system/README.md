# 🧪 Lab 9 — Multi Device IoT System

## 🎯 Objective
Build a system that supports multiple ESP8266 devices sending telemetry to one server.

---

## ⚙️ What This Lab Teaches
- Device identity (device_id)
- Multi-node IoT architecture
- Fleet monitoring
- Data aggregation

---

## 🧠 Architecture

Multiple ESP8266 → Flask Server → JSON Storage → Dashboard

---

## 📡 Features

- Multiple devices supported
- Live dashboard
- Inventory tracking
- Latest data API
