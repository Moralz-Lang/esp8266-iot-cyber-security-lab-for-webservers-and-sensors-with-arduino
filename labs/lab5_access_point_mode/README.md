# 🧪 Lab 5 — ESP8266 Access Point Mode

## 🎯 Objective
Turn ESP8266 into a standalone WiFi hotspot with its own web server.

---

## ⚙️ What This Lab Teaches
- Access Point (AP) mode
- Embedded networking
- Offline IoT systems
- Direct device communication

---

## 📡 How It Works

ESP8266:
1. Creates WiFi network: `ESP-LAB-5`
2. Devices connect directly
3. Web server runs locally

---

## 🌐 Connection Steps

1. Power ESP8266
2. Connect to WiFi:
   - SSID: ESP-LAB-5
   - Password: 12345678
3. Open browser:

---

## 🧠 WHAT THIS LAB DOES

* ✔ ESP8266 creates its own WiFi network
* ✔ Your phone/PC connects directly to it
* ✔ Web server runs without router
* ✔ Foundation for isolated IoT networks
