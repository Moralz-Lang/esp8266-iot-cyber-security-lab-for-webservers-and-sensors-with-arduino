# 🧪 Lab 2 — Multi-Page Web Server (ESP8266)

## 🎯 Objective
Build a multi-page web interface using ESP8266 with multiple HTTP routes.

---

## ⚙️ What This Lab Teaches
- HTTP routing
- Multi-page IoT dashboards
- JSON API creation
- Network info retrieval

---

## 📡 Routes Created

| Route | Description |
|------|-------------|
| `/` | Main dashboard |
| `/status` | System status |
| `/network` | WiFi info |
| `/api` | JSON API |

---

## 🔌 Hardware
- NodeMCU ESP8266

---

## 🌐 Example Output

- http://192.168.x.x/
- http://192.168.x.x/status
- http://192.168.x.x/network
- http://192.168.x.x/api

---

## 🧠 WHAT LAB 2 DEMONSTRATES

✔ Multi-page web server
✔ IoT routing system
✔ JSON API endpoint
✔ Device network visibility
